# CineGo – Movie Booking (Frontend)

A front-end movie booking platform with multiple screens: home, what’s on, trailers, membership, login/signup, seat booking, and checkout/confirmation.

## ✨ Features
- Browse “What’s On” and watch trailers
- Search movies (by title)
- User auth screens (login / join)
- Membership management
- Seat selection and booking flow with confirmation
- Food & drink upsell during checkout

## 🗂️ Tech
- HTML, CSS, JavaScript (vanilla)
- Responsive layout
- Modular JS per page (e.g., `booking.js`, `searchmovies.js`, `trailer.js`)
